STUDIO / PERMISSIONS

Words are not permissions.

Microphone, input access, network providers, filesystem tools, and side effects each need an explicit boundary.

BOUNDARY CENTER

Know what leaves the canvas.

01Dry-run before consequence.+

A spoken request is only an intent proposal. The runtime should show the requested capability, target, and expected effect before a tool runs; side effects use dry-run and explicit approval by default in the source direction.

  • Show target and scope
  • Dry-run first
  • Approval is a separate state
02Permission state must be inspectable.+

Requested, granted, denied, expired, and unknown states must remain separate; this is not a security certification.

  • Denial is recoverable
  • Unknown never becomes allowed
