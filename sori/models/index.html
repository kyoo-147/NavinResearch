STUDIO CONTROL ROOM

Advanced surfaces stay behind the daily gesture.

PANEL 01

Route by the moment.

A model choice belongs to the current context: language, active app, device budget, privacy mode, and whether a local model is warm. The README names local and cloud/BYOK directions, with whisper.cpp as an initial baseline rather than a permanent boundary.

  • Context selects a route
  • Local and BYOK paths stay distinct
  • Warm or cold state is observable
PANEL 02

No benchmark result is published here.

Latency, WER, memory, and fallback behavior require a reproducible run on a named machine and remain unreported on this public site.

  • No quality ranking
  • No hardware matrix
  • Fallback remains to be verified
