PROGRAMMABLE VOICE RUNTIME

Sori

A quiet, local-first voice runtime for desktop work.

Sori is a Windows-first desktop MVP foundation: a small instrument for speaking into the active app, with the runtime, permissions, and boundaries kept visible when they matter.

BETA INTEREST ONLY

01 / THE HOT PATH

A voice gesture, not another destination.

The intended daily path is compact: grant permissions, hold a hotkey, speak, release, and let text meet the focused app. The overlay stays small and appears for listening, preview, or attention.

  • Hold-to-speak interaction
  • Tiny overlay and tray presence
  • Focused-app insertion is an explicit boundary

02 / THE INSTRUMENT

Programmable beneath the surface.

A desktop shell can talk to a local Sori daemon over bounded loopback IPC. Context, audio, routing, history, profiles, skills, and permissions are arranged as runtime concerns rather than a dashboard of promises.

  • Rust daemon with loopback IPC
  • Local SQLite metadata and history
  • Progressive disclosure from basic to expert

03 / THE BOUNDARY

Useful, with the unknowns marked.

Sori keeps audio local-first by default in its product direction and gates side effects behind dry-run and approval. The current foundation is not presented as a verified physical voice vertical slice.

  • Cloud and local providers can be routed deliberately
  • Side effects require explicit approval by default
  • Physical microphone and insertion evidence remain UNVERIFIED
