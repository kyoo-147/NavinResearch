STUDIO / ADVANCED

Open the instrument only when you need it.

Sori keeps daily dictation quiet, then progressively discloses models, profiles, diagnostics, history, and permissions in Studio.

01

Basic first. Advanced when useful.

The source README describes a Studio and CLI path for configuration, diagnostics, models, extensions, and harnesses. This page is an information architecture, not a shipped interface.

02

The daemon remains canonical.

The desktop shell is intended to talk to the local daemon over bounded loopback IPC; physical delivery and live runtime behavior remain machine-dependent.
