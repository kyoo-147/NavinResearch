## Generation prompts

- Human proximity wide: quiet home workspace, hands near keyboard and understated microphone, natural window light, no readable screen/UI/logo/text, warm charcoal/cream/amber palette.
- Human proximity macro: close-up of one hand, compact microphone, keyboard and notebook, screen absent, restrained natural side light, no branding/text/interface.
- Signal acoustic field: tactile paper/charcoal field showing an abstract voice signal crossing a boundary, restrained amber accent, no product claim.

All WebP files use quality-focused local compression. The reconstructed UI studies bake in an explicit `SIMULATED UI / UNVERIFIED` boundary and contain no copied proprietary reference artwork or third-party brand marks.
