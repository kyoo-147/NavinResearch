03 / ORCHESTRATION

Route work without hiding judgment.

Workflow steps connect workers and approvals. Sandora is designed to pause when context is missing or a consequential decision needs a person.

  1. 01

    Route the work

    A workflow is a route through roles and checkpoints. Missing context should be visible instead of silently pushed forward.

    CONCEPT-STAGE
    1. Attach context
    2. Record each handoff
    3. Pause at uncertainty
    Read approvals →
  2. 02

    Choose the gate

    Consequential choices belong to an explicit checkpoint, not an invisible prompt or an implied autonomous action.

    CONCEPT-STAGE
    1. Trigger
    2. Handoff
    3. Approval

Keep the boundary visible.
