# Sandora microsite reference

## Product direction

Sandora is presented as a **prototype preview** for an operating layer that helps people coordinate teams of AI agents. The page deliberately describes the product story (context, coordination, confidence) without implying that a production service, waitlist backend, or live integrations exist.

## Interaction boundary

The early-access form is intentionally demo-only. It prevents submission and writes only a status message in the current page; no network request or data collection occurs. Copy says this explicitly near the form.

## Design notes

The visual language uses an editorial, botanical palette and constellation/orbit illustration to distinguish Sandora from a conventional SaaS/Hermes treatment. It is responsive at narrow widths, uses semantic sections/headings, descriptive image alt text, a skip link, visible focus styling, and a live status region for the demo interaction.
