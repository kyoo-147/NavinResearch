LIFE WITH LAJVARD / SCENARIO

Start with the morning, not the dashboard.

A companion earns trust through small, legible moments: a greeting you can dismiss, a memory you can edit, a pause you understand.

01

A day in four gestures.

Wake, notice, remember, rest. These are story beats for design exploration, not a claimed user experience.

SCENARIO
  • Say hello without demanding attention
  • Notice a change without inventing a reason
  • Rest when the owner asks
02

Presence should remain dismissible.

The person in the room should be able to pause listening, clear a memory, or ask what the robot knows.

DESIGN REQUIREMENT
  • Dismiss the interaction
  • Inspect the memory
  • Choose when to continue
