INTELLIGENCE / SOFTWARE STATES

Software should explain itself.

The software direction favors visible state: listening, thinking, remembering, offline, unavailable, and waiting for permission.

01

State before spectacle.

A future companion needs understandable controls for journals, network access, updates, and recovery. No Lajvard software is currently released.

UNBUILT
  • Clear listening indicator
  • Export and delete journal data
  • Fail closed when identity is uncertain
02

The safest answer can be no.

When identity, network, or perception is uncertain, the software should stop and explain the boundary rather than improvise confidence.

DESIGN REQUIREMENT
  • Offline is explicit
  • Permission is revocable
  • Recovery is observable
