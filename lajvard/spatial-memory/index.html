THE ROBOT / ROOM MEMORY

Remember less. Remember clearly.

Spatial memory should be a readable relationship with a place, not an invisible dossier.

  1. 01

    A map with an eraser.

    Scene understanding is an established research area; Lajvard has no mapping implementation. Any future map would need inspection, correction, expiry, and deletion.

    INTENDED
    1. Show what was remembered
    2. Let the owner correct it
    3. Clear it without a support ticket
  2. 02

    Memory needs a source and an expiry.

    A remembered object should explain when and how it entered the journal, and when it will be forgotten. This is a design requirement, not a storage claim.

    DESIGN REQUIREMENT
    1. Provenance before convenience
    2. Owner-controlled retention
    3. No hidden household profile
