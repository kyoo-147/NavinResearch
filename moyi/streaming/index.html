STREAMING

Work with the utterance as it arrives.

Moyi studies incremental audio and language paths while keeping partial output distinguishable from reviewed output.

01

Partial is not final.

A streaming interface must make state, interruption, and uncertainty observable. Latency and throughput are not published.

02

State changes need a timestamp.

Incremental output can change as more audio arrives. The interface should distinguish a partial hypothesis from a reviewed handoff.
