Test the idea before the track.

Simulation can make assumptions cheap to inspect. It cannot be presented as a physical run or real-world benchmark.

01

Synthetic is synthetic

Charts, trajectories, and overlays on this page are diagrams of an evaluation method, not results from a real episode.

SIMULATION / NOT PHYSICAL EVIDENCE
  • Simulation setup must be identified
  • Synthetic traces are not physical proof
  • No result values are claimed
02

Name the handoff

A useful simulation record captures the map, sensor model, controller configuration, scenario, seed, and failure outcome. Without that receipt, a smooth line is only an illustration.

PROTOCOL BEFORE METRIC
  • Scenario and map revision
  • Inputs and assumptions
  • Outcome and failure log
03

A synthetic track still needs a receipt.

Simulation is valuable when map revision, sensor assumptions, controller settings, seed, and failure conditions travel with the trace. A clean trajectory alone is not evidence of physical behaviour.

SYNTHETIC RECORD
  • Scenario and map identity
  • Synthetic sensor assumptions
  • Failure and replay record
