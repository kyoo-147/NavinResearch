Questions before conclusions.

Use the platform to ask what changed, what was measured, and what remains unknown.

01

A reproducible posture

A useful study records setup, source revision, sensor inputs, intervention, and limitations before interpreting a trace.

RESEARCH METHOD
  1. State the source revision
  2. Separate observation from inference
  3. Preserve failed runs and unknowns
02

A result needs a receipt

For autonomy, evidence should identify whether a view is source material, simulation, supervised physical testing, or public-road operation. This project page only claims the first two categories.

EVIDENCE TAXONOMY
  1. Source image or repository fact
  2. Simulation trace
  3. Physical episode only with capture

Read the source trail
