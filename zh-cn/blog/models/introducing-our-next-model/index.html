关于 afaxxaq-000 — unname 的发布前说明：这是一款正在测试并等待公开发布的 Navin Research 多模态 open-weight 模型。

简要回答: afaxxaq-000 — unname 是 Navin Research 一款正在测试并准备公开发布的模型的临时名称。它被设计为能够在对话中学习、保留用户记忆、适应不同用户与工作，并通过 memory、知识库/RAG、工具、工作流、fine-tuning 与 adapters 实现高度定制。它尚未正式发布；价格、基准结果与定量规格尚未公布。

01 / 我们正在准备的模型

afaxxaq-000 — unname 正等待正式介绍。

afaxxaq-000 — unname 是一款正在测试并准备公开发布的 Navin Research 模型的临时工作名称。它还不是已经发布的产品，但已经有明确的模型方向：多模态能力、广泛的可定制性，以及能够通过使用和有意识的调校而改进的行为。

这个名称只是工作名称。模型准备好后，发布记录会用正式身份替换这个临时名称。

  • 状态：正在测试并等待公开发布
  • 工作名称：afaxxaq-000 — unname
  • 发布形式：OPEN-WEIGHT

02 / 学习与适应

学习意味着变得更有用，而不只是变得更大。

afaxxaq-000 被设计为在多个层面学习。在一次对话中，它可以使用当前交流作为上下文。通过用户控制的 memory，它可以在多次对话之间保留相关信息。通过私有数据、fine-tuning 或 adapters，它可以适应某个领域、组织或工作流。

模型也可以在部署后被有意调整。这意味着介入模型的行为和目标，使系统工作得更正确、更一致、更精确。这并不意味着声称基础模型每次学习后都会变大。

  • 对话中的学习
  • 用户控制的长期记忆
  • 基于私有数据的 FINE-TUNING 或 ADAPTERS
  • 部署后的行为调校

03 / 高度定制

模型应该适应工作，而不是强迫每位用户使用同一种行为。

定制是模型方向的核心部分。用户可以配置 afaxxaq-000 为自己工作；memory、知识库检索、工具、工作流、fine-tuning 与 adapters 构成不同的控制层。

这些层有不同用途。Memory 维持与用户有关的连续性。Retrieval 把受治理的外部知识带入任务。工具与工作流把模型连接到行动。Fine-tuning 与 adapters 针对领域或运行方式改变行为。用户可以选择并组合这些机制，而不是把定制理解成一个不透明的开关。

  • 用户可以自行配置
  • MEMORY 与知识检索
  • 工具与工作流
  • FINE-TUNING 与 ADAPTERS

04 / 多模态工作

文本、语音与视觉属于同一个模型方向。

模型方向包括 text、speech 与 audio、vision 与 image，以及结合这些输入的多模态工作。这为个人助理、研究、企业工作与工作流自动化提供基础，而不是只服务于一种狭窄界面。

Moyi 仍然是独立项目。Moyi 专注于语音技术及其自身的研究方向；它不是 afaxxaq-000 的名称，也不应被描述为该模型的组成部分。

  • TEXT
  • SPEECH 与 AUDIO
  • VISION 与 IMAGE
  • 多模态输入与输出
  • MOYI：独立项目

05 / OPEN-WEIGHT 与访问

发布方向支持不止一种工作方式。

afaxxaq-000 的发布方向是 open-weight。计划中的使用方式不局限于一个封闭界面。具体的软件包、API、运行时、硬件建议与访问条件，会在准备好后由发布记录说明。

Open-weight 可以支持检查、本地控制、领域适配与独立实验。同时，运营方需要负责模型周围的运行时、数据边界、权限、安全控制与维护。

  • OPEN-WEIGHT 方向
  • 多种计划中的使用方式
  • 具体软件包与访问：尚未公布
  • 价格：尚未公布

模型公告必须说明模型被如何测试。

模型目前正在测试，但基准结果、内部测试数字、支持语言范围、context window、速度与其他定量规格尚未获准公开。因此，本文只描述已确认的方向，不把测试过程变成性能声明。

发布前，评估记录需要把模型行为与 memory、retrieval、工具、工作流编排、运行时和人工审阅分开。它也应说明系统在哪些地方会拒答、失败或需要人来决定。

  • 测试：进行中
  • 基准与数字：尚未公布

07 / 模型的用途

一个可适应的基础，许多负责任的用途。

目标范围包括个人助理、研究、企业工作、工作流自动化和多领域使用。这些类别描述的是方向，并不保证每项任务都能得到同样好的解决。合适的配置、数据、工具、权限与审阅边界取决于具体工作。

模型应该帮助个人与组织围绕自身需要塑造有用系统，同时让重要行动保持可检查、可控制。

  • 个人助理
  • 研究
  • 企业工作
  • 工作流自动化
  • 多领域使用
